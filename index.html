Every game

Predicted score comes from the model: team ratings for scoring, play-by-play efficiency, returning production and roster talent, updated with every game played.
Hit % is how often bets like this one actually won when the model was tested on the 2023–2025 seasons. For moneylines it blends the model with the market odds, because the market proved more accurate on its own.
Return per $100 is the average result if you made this bet many times: hit % × payout, minus the stake. Moneylines use the best price found across sportsbooks; spreads and totals assume standard −110.
QB alerts flag teams whose usual starting quarterback missed their last game or has shared time. The model does not adjust for this yet, so check those games before betting.
Best bets by expected return (the ranked list) did not beat the sportsbooks in testing; it is mainly useful for finding the best price. The model's best bets above follow the rules that did hold up in testing.
Line status: "Bet now" means the gap between the model and the current line still meets the rules. "Line moved" means the number has shifted since it opened and most of the edge is gone.
